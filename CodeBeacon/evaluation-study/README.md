# Evaluation study

The answer key is in [application-constants.xlsx](application-constants.xlsx), in the **Version A** and **Version B** tabs. These tabs record vulnerability locations, code, behavior, and explanations. The **Vulnerabilities** tab defines the ten target types.

- [Answer key comparison table](answer-key.md): expected Found/Missing results for all ten targets in each version, with locations and matching evidence.
- [Scoring rubric](scoring-rubric.md): the agreed 1/0.5/0 scoring procedure, with a maximum of ten points per detector per version.
- [Results notes](results-notes.md): where the LLM and scanner outputs go and what to expect in the files.
- [LLM workflow](llms/llm-evaluation-workflow.md): exact PowerShell commands, saved responses, grading, and comparison steps.

Keep the workbook, answer key, and rubric outside the application packages supplied to detectors.
